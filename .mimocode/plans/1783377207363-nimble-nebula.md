## 实现计划（按优先级排序）

### Phase 1: 启动界面（面板 1+2）
- 文件: `yam/ui/pages/splash.py`
- 三列级联选择器
- 搜索框
- 采集状态显示
- "进入主界面" / "开始爬取" 按钮

### Phase 2: 主界面框架（面板 3 状态栏部分）
- 文件: `yam/ui/app.py`
- 底部状态栏：专业/更新时间/院校数/收藏数/对比数
- 菜单栏：文件/数据/视图/帮助 + 搜索图标 + 设置图标

### Phase 3: 学院卡片重设计（面板 3 卡片部分）
- 文件: `yam/ui/pages/schools.py`
- 新卡片布局：招生人数分数显示 + 分数线趋势箭头 + 异常警告横幅
- 对比复选框

### Phase 4: 展开详情（面板 4）
- 文件: `yam/ui/pages/schools.py`
- 内联展开：基本信息 + 分数线表格(年份tab) + 考试科目 + 研究方向

### Phase 5: 对比弹窗（面板 5）
- 文件: `yam/ui/pages/compare.py`
- 模态弹窗，3列并排，差异黄色高亮

### Phase 6: 表格视图（面板 8）
- 文件: `yam/ui/pages/schools.py`
- 表格布局 + 分页

### Phase 7: 导出弹窗（面板 6）
- 文件: `yam/ui/app.py` 或新文件
- 范围/内容/格式选择

### Phase 8: 设置窗口（面板 11）
- 文件: 新文件 `yam/ui/pages/settings.py`
- 左侧 tab + 右侧内容

### Phase 9: 深色模式（面板 9）
- 文件: `yam/ui/theme.py` + `yam/ui/app.py`
- 暗色色板 + 切换逻辑

### Phase 10: 数据更新弹窗（面板 10）
- 文件: 新功能
- 检查更新 + 选择更新
