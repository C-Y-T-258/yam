# YAM UI 全面重做计划

## 核心问题

当前 UI 架构与用户期望完全不匹配：
- 布局：卡片网格 vs 用户要的全宽列表视图
- 交互：页面跳转 vs 用户要的内联展开 + 模态弹窗
- 流程：每次选专业 vs 用户要的"有数据直接进"
- 功能：缺失菜单栏、深色模式、添加专业入口、状态栏

## 用户完整期望（从 Kimi 对话提取）

### 使用流程
```
启动 → 检查本地数据
  ├─ 有数据 → 直接进入主界面
  └─ 无数据 → 启动界面（帮助用户找到专业）
        ├─ 搜索框：输入专业名称/代码模糊搜索
        ├─ 专业列表：显示所有可选专业，可点击选择
        └─ 手动输入：直接输入专业代码
        → 选择/输入后 → 爬取(浮动进度卡片) → 进入主界面

主界面内：
  菜单栏 → 数据 → 添加新专业(搜索/选择/输入) → 浮动进度 → 自动添加到列表
  筛选面板 → 专业区域显示已添加的所有专业，可勾选
  所有院校在同一列表中展示（支持多专业数据混合）
```

### 启动界面设计
- 居中大标题 "研喵 YAM" + 副标题
- 搜索框："搜索专业名称或代码..."
- 专业列表：显示所有专业（代码 + 名称 + 状态）
  - 已采集：绿色对勾 + 院校数量，点击直接进入
  - 未采集：下载图标，点击触发爬取
- 底部："手动输入专业代码" 链接 → 弹出输入框
- 整体风格：干净居中，Notion/Figma 极简感

### 页面架构
```
┌─────────────────────────────────────────────────────┐
│  ≡  研喵 YAM    文件    数据    视图    帮助         │  ← Fluent 菜单栏
├──────────┬──────────────────────────────────────────┤
│          │  🔍 搜索...  [排序▼] [对比 0/3] [导出]   │  ← 顶部操作栏
│  筛选面板 │                                          │
│  (可折叠) │  ┌────────────────────────────────────┐  │
│          │  │ 院校1 (全宽，一行一所)              │  │
│  层次    │  │ [展开详情] 内联展示                 │  │
│  地区    │  ├────────────────────────────────────┤  │
│  专业    │  │ 院校2 (全宽)                       │  │
│  科目    │  │ ...                                │  │
│          │  └────────────────────────────────────┘  │
│          │  共 217 所 | 收藏 12 所 | 已选 2/3 对比   │  ← 状态栏
└──────────┴──────────────────────────────────────────┘
```

### 院校卡片（列表视图，默认）
- 全宽，一行一所
- 内容：校名 + 收藏按钮 + 对比复选框 + 标签(层次/地区/专业) + 招生人数 + 分数线趋势 + 展开/收起按钮
- 点击"展开详情"：卡片向下扩展，内联显示院系所/分数线表格/考试科目/研究方向/招生计划
- 点击"收起"：恢复折叠状态

### 对比功能
- 模态弹窗，2-3 列并排
- 差异项黄色高亮
- 空位可选择院校填入

### 菜单栏
- 文件：导出CSV、退出
- 数据：添加新专业(输入代码)、刷新数据、数据审计
- 视图：布局切换(列表/紧凑/网格)、筛选面板显示/隐藏
- 帮助：使用说明、关于

### 爬取进度
- 右下角浮动卡片（非模态）
- 显示专业代码 + 进度条 + (67/217)
- 可展开查看日志流
- 爬完自动消失

### 视觉风格
- Notion/Figma 极简风 + Windows Fluent
- 默认浅色模式
- 主色：#0f3460（深蓝）
- 圆角 12px、微妙阴影、大量留白

## 与当前实现的差距

| 维度 | 当前 | 目标 | 差距 |
|------|------|------|------|
| 启动流程 | 每次选专业 | 有数据直接进 | 架构不同 |
| 主布局 | 卡片网格 | 全宽列表 | 重做 |
| 详情展示 | 独立页面 | 内联展开 | 重做 |
| 对比 | 独立页面 | 模态弹窗 | 重做 |
| 筛选面板 | 顶部 | 左侧可折叠 | 移动 |
| 菜单栏 | 无 | Fluent 风格 | 新增 |
| 状态栏 | 无 | 底部信息栏 | 新增 |
| 添加专业 | 无 | 输入任意代码 | 新增 |
| 深色模式 | 无 | 手动切换 | 新增 |
| 爬取进度 | 独立页面 | 浮动卡片 | 重做 |

## 重做范围

这是一次**架构级重做**，不是修补。需要重写：
1. `app.py` — 主框架（菜单栏 + 筛选面板 + 主内容区 + 状态栏）
2. `pages/dashboard.py` → 删除（不需要独立首页）
3. `pages/schools.py` → 重写为列表视图 + 内联展开
4. `pages/detail.py` → 删除（详情内联到列表中）
5. `pages/compare.py` → 重写为模态弹窗
6. `pages/favorites.py` → 改为筛选面板内的快捷开关
7. `pages/fetch.py` → 重写为浮动进度卡片
8. `pages/about.py` → 移到菜单栏帮助菜单
9. `pages/splash.py` → 改为仅在无数据时显示的弹窗
10. `theme.py` — 调整颜色系统

## 验证方式

启动应用，Chrome DevTools 逐页截图验证：
1. 有数据时直接进入主界面
2. 列表视图一行一所院校
3. 展开详情内联显示
4. 对比模态弹窗
5. 菜单栏功能
6. 浮动爬取进度
