# 研喵 YAM

本地优先的考研择校数据工具。

```
 🐱  YAM = 研喵 = 你的考研择校小助手
```

## 特性

- **本地爬取**：数据直接从研招网、掌上考研等公开渠道获取，存在你的本地数据库
- **本地展示**：启动后通过 NiceGUI 桌面窗口浏览，无需联网即可查看已抓取数据
- **多专业支持**：先聚焦 085410 人工智能，后续逐步扩展至所有考研专业
- **数据透明**：每条数据标注来源和更新时间，自动审计排查异常

## 安装

```bash
pip install kaoyan-yam
```

## 快速开始

```bash
# 查看支持的专业
yam list-majors

# 抓取 085410 人工智能数据
yam fetch --major 085410

# 查看数据完整率
yam stats --major 085410

# 启动桌面 UI（需安装 ui 依赖）
yam serve --major 085410
```

## 数据说明

数据来自研招网（yz.chsi.com.cn）、掌上考研等公开渠道，仅供学习参考，请以官方最新信息为准。
