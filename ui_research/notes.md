# YAM 桌面 UI 重新设计研究笔记

## 研究目标
为 YAM（研喵）考研择校桌面应用重新设计一套功能完整、视觉现代、交互清晰的 UI，参考各行业成功桌面应用与教育/选校类产品。

## 资料结构
- `dashboard_general/`：通用 Dashboard / SaaS / 数据表格设计案例
- `education/`：教育、学生、选校类产品案例（含国内外）
- `desktop_apps/`：桌面应用侧边导航与布局模式

---

## 一、各行业成功案例的共同点

### 1. 布局：左侧固定导航 + 顶部工具栏
几乎所有复杂桌面应用（CRM、ERP、教育后台、数据分析工具）都采用：
- 左侧固定侧边栏（Sidebar）：放置主导航、收藏、设置
- 顶部工具栏：搜索、筛选、通知、用户操作
- 主内容区：可滚动，使用卡片/表格展示数据

**好处**：
- 导航始终可见，用户不会迷路
- 主内容区空间充足
- 符合 SaaS / 桌面应用的心智模型

**代表案例**：
- Vento 财务 Dashboard
- ICarePro 医疗后台
- Trackify CRM
- EduTrack 学校管理后台

### 2. 首页：数据概览 + 快速入口
成功产品的首页不是直接罗列详细数据，而是：
- 大数字 KPI 卡片（总数、变化趋势、异常数量）
- 快捷操作入口
- 最近查看/重点关注
- 数据健康度提示

**对 YAM 的启示**：
- 首页展示：收录院校数、有异常院校数、可关注院校数、数据更新时间
- 明显的“异常提醒”入口
- 最近查看的院校

### 3. 列表页：卡片/表格 + 强大筛选
数据量较大时，两种展示模式并存：
- 卡片视图：适合浏览，信息密度低，视觉友好
- 表格视图：适合对比，信息密度高，支持排序

**必备筛选能力**：
- 搜索框
- 多选下拉（省份、层次）
- 范围筛选（招生人数、分数线）
- 排序切换
- 已选筛选标签（Filter Chips）

**代表案例**：
- shadcn/ui Data Table 模板
- Setproduct 数据表格设计指南
- 圆梦志愿找大学

### 4. 详情页：顶部摘要 + Tab/卡片分组
详情页通常：
- 顶部放最重要信息（名称、关键标签、核心指标）
- 下方用 Tab 或卡片分组展示不同维度数据
- 用标签/徽章（Badge）突出异常或特色

**代表案例**：
- 圆梦志愿大学详情：大图 + 关键属性 + 发展历程 + 底部 Tab
- iStudent 课程详情

### 5. 对比功能：并排展示 + 差异高亮
选校类产品的核心功能之一是对比：
- 并排展示 2-4 个选项
- 相同属性对齐，方便比较
- 用颜色/徽章标出优势项

**代表案例**：
- CampusReel Compare Colleges
- shadcn Product Card Comparison
- 圆梦志愿大学对比

### 6. 视觉风格：浅色、大圆角、柔和阴影
2026 年主流桌面应用风格：
- 浅色背景（白色/浅灰）
- 大圆角卡片（12-20px）
- 柔和阴影或无边框卡片
- 重点色突出（蓝色/紫色/橙色）
- 清晰的字体层级

**代表案例**：
- Vento Dashboard
- iStudent
- EduTrack

## 二、教育/选校类产品的特色

### 1. 数据权威感很重要
教育类产品必须让用户觉得数据可信：
- 明确标注数据来源
- 展示数据更新时间
- 异常数据明显提醒
- 官方合作/备案标识

**参考**：
- 圆梦志愿：标注教育部 APP 备案号
- 阳光高考：教育部官方平台
- College Navigator：美国教育部官方数据

### 2. 信息层次复杂，需要逐步展开
一所学校有很多维度：
- 基本信息（省份、层次、公办/民办）
- 招生数据（招生计划、历年分数线）
- 学科实力（硕博点、学科评估）
- 考试科目、研究方向
- 就业报告

**好的做法**：
- 首页只展示最关键指标
- 详情页用 Tab/折叠卡片分层展示
- 不要一次性把所有信息堆出来

### 3. 搜索和筛选是核心交互
选校产品用户通常有明确偏好：
- 按省份筛选
- 按学校层次筛选（985/211/双一流/普通）
- 按招生人数/分数线排序
- 按考试科目筛选

**参考**：
- BigFuture：按专业、地点、大小、氛围筛选
- 圆梦志愿：按冲/稳/保推荐
- 掌上高考：按分数/位次智能匹配

### 4. 辅助决策功能受欢迎
- 录取概率预测
- 冲/稳/保推荐
- 智能填报
- 收藏/关注列表

虽然 YAM 目前不做预测，但可以提供：
- 异常数据提醒
- 收藏夹
- 院校对比
- 数据趋势图表

## 三、YAM 桌面应用设计建议

### 1. 整体布局
```
┌─────────────────────────────────────────────────────┐
│  Logo / 标题    搜索    筛选    通知    设置/帮助     │  ← 顶部工具栏
├──────────┬──────────────────────────────────────────┤
│ 首页     │                                          │
│ 院校库   │          主内容区                        │
│ 数据对比 │          （首页/列表/详情/对比）          │
│ 我的收藏 │                                          │
│ 数据说明 │                                          │
│──────────│                                          │
│ 设置     │                                          │
└──────────┴──────────────────────────────────────────┘
```

### 2. 功能清单（必须全）
- [ ] 首页数据看板
- [ ] 院校库列表（卡片+表格双视图）
- [ ] 多维度筛选与排序
- [ ] 院校搜索
- [ ] 院校详情页
- [ ] 院校对比（2-3 所并排）
- [ ] 收藏夹/关注列表
- [ ] 数据异常提醒
- [ ] 数据来源说明
- [ ] 导出数据（CSV）
- [ ] 数据更新状态

### 3. 页面详细设计

#### 首页
- 顶部横幅：数据更新时间 + 数据来源说明
- KPI 卡片：
  - 收录院校总数
  - 数据正常院校数
  - 异常提醒院校数
  - 我的收藏数
- 快捷入口：院校库、异常数据、我的收藏、数据对比
- 最近查看院校
- 数据质量概览（饼图/进度条）

#### 院校库
- 顶部：搜索 + 筛选栏 + 视图切换（卡片/表格） + 排序
- 筛选条件：
  - 省份（多选）
  - 学校层次（985/211/双一流/普通本科）
  - 招生年份
  - 招生人数范围
  - 分数线范围
  - 数据来源
  - 是否有异常
- 卡片视图：学校名称、省份、层次标签、招生人数、分数线、异常标记、收藏按钮
- 表格视图：多列对比，支持排序

#### 院校详情
- 顶部：学校名称、省份、层次标签、收藏按钮、异常提醒
- 信息 Tab：
  - 招生信息（研招网 + 掌上考研对比）
  - 历年分数线（趋势图 + 表格）
  - 考试科目
  - 研究方向
  - 数据异常说明
- 底部：数据来源、采集时间

#### 数据对比
- 选择 2-3 所院校并排展示
- 对齐关键指标：招生人数、分数线、考试科目、学校层次
- 高亮差异项
- 可导出对比表

#### 我的收藏
- 用户关注的院校列表
- 快速查看关键指标
- 一键对比

#### 数据说明
- 数据来源列表
- 异常数据处理规则
- 如何验证数据
- 免责声明

### 4. 视觉风格
- 主色调：蓝色系（可信、教育感）
- 异常色：橙色/红色
- 成功/正常色：绿色
- 背景：浅灰/白色
- 卡片：白色背景、大圆角、柔和阴影
- 字体：清晰的无衬线字体，层级分明
- 图标：简洁的线性图标

### 5. 交互细节
- 卡片 hover 效果
- 筛选标签可一键清除
- 表格列可排序
- 详情页可分享到对比
- 收藏状态实时同步
- 异常数据点击展开详情
