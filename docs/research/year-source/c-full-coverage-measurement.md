# C：全量覆盖测算

## 口径

当前产品全集由桌面库的 4 个专业、461 个来源学校 ID、855 个学校-专业组合、1217 个院系实体和 2961 个当前计划构成。分别乘 2023-2026 四届后，精确分母为：

| 实体层级 | 当前实体 | 四届实体切片 |
|---|---:|---:|
| 专业 | 4 | 16 |
| 学校 | 461 | 1844 |
| 学校-专业 | 855 | 3420 |
| 院系 | 1217 | 4868 |
| 方向/具体计划 | 2961 | 11844 |

复现命令：

```powershell
python -m yam.scripts.audit_year_sources --pretty --output docs/research/year-source/evidence/local-audit.json
python -m yam.scripts.measure_year_source_coverage --pretty --output docs/research/year-source/evidence/coverage-statistics.json
```

第一步以 SQLite `mode=ro` 和 `query_only` 读取用户库并校验前后哈希；第二步只读取聚合审计 JSON。机器结果见 [`evidence/coverage-statistics.json`](evidence/coverage-statistics.json)，其中保存分子、分母、百分比、SQL 查询 ID 和排除规则。

## 当前产品实体 × 2023-2026 精确覆盖率

### 年度目录

2961 个当前计划的 `catalog_year` 全 NULL，`catalog_year_status` 全是 `unknown`。因此院系、方向、学习方式、考试方式、考试科目、拟招人数、专项计划和“是否招生”八类年度字段，在 11844 个计划-届次切片上的确定覆盖均为 **0 / 11844 = 0%**。

按实体映射层级计算也全部为零：学校 0/1844、专业 0/16、学校-专业 0/3420、院系 0/4868、具体计划 0/11844。这里的零是“当前本地没有确定年度事实”，不是“这些实体四届均不招生”。`workspace_department_years` 的 9135 行是把共享分数投影到当前院系，未计入目录分子。

### 分数

本地桌面模型在学校-专业层有 2454 个去重的年度分数参考记录：

| 届次 | 参考记录覆盖 | 学校-专业分母 | 比例 |
|---:|---:|---:|---:|
| 2023 | 490 | 855 | 57.3099% |
| 2024 | 595 | 855 | 69.5906% |
| 2025 | 670 | 855 | 78.3626% |
| 2026 | 699 | 855 | 81.7544% |
| 合计 | 2454 | 3420 | 71.7544% |

这 71.7544% 只能称为 `untyped_score_reference` 覆盖。源表 3855 行中有 2950 行缺少 `metric_type/match_scope`；其余只区分专业码、一级学科或门类匹配，没有能够回到来源语义的国家线、校线、院线、专业线、方向线严格类型。因此五种严格分数覆盖分别是 **0 / 3420 = 0%**。不能用“学校-专业关联成功”替代分数发布粒度。

### 录取

本地没有录取统计表或事实。按 3420 个学校-专业-届次切片计算，录取人数、初试最低分、平均分、最高分、复试成绩和最终总成绩均为 **0 / 3420 = 0%**。阶段 B 的深圳大学官方长图是深度样本，不属于当前产品库，也没有扩展到全部专业，因此不计入全量分子。

旧 `admission_plans` 的 781 行只覆盖 `085410`，且没有任何已确认映射到当前具体计划的记录，故其当前计划覆盖分子仍是 0。2023 第三方空结果也不计为不招生。

## 轻量全量测算边界

本次全量测算只扫描已有聚合事实，不向 461 所学校批量发送外部请求。阶段 B 已用少量代表样本确认来源能力和解析风险；在没有采集契约、限速预算、版本留证和实体映射队列前，对全部学校抓取会制造无法审计的混合事实，也超出“不启动 ISSUE-032 正式接入”的边界。

外部深度样本不外推为全产品覆盖。即使南京大学四届目录完整，也不能把其能力推算为其他 460 个来源学校的覆盖；即使研招网国家线四届存在，也不能复制成每个学校-专业的专业线。

## 全国招生组合口径

全国招生组合覆盖率为 **不可计算（`not_computable`）**，没有百分比。原因是本次没有获得 2023-2026 每届完整、版本化、可枚举的全国“学校-院系-专业-方向-学习方式-考试方式-专项计划”官方全集。研招网当前接口无显式年份参数；各校历史目录载体和实体定义不统一；第三方历史接口存在缺年和 ID 不兼容。

未来只有在每一届建立完整全国官方目录清单、保存来源版本，并完成代码/名称变更映射后，才能形成全国分母。此前可报告“已验证学校数”“已获得官方目录数”和“当前产品实体覆盖率”，不得报告全国覆盖百分比。

## 阶段 C 结论

当前产品真正可报告的年度能力是：目录 0%，严格分型分数 0%，录取六字段 0%；另有 71.7544% 的学校-专业-届次存在未严格分型的分数参考记录。这个结果低但边界确定，直接说明后续接入的首要工作是来源声明届次、严格事实类型和实体映射，而不是把现有分数年份包装成年份详情。
