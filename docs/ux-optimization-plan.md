# YAM 桌面端用户体验优化计划

> 生成时间：2026-07-24  
> 来源：基于全流程 UI 测试与代码检查整理，经用户逐项确认后生成。

本文档记录当前确认采纳的用户体验优化项。未采纳的模块在文末「暂不处理模块」中说明原因。

---

## 采纳模块与优化项

### 1. 首次使用 / 空状态

#### 1.1 修复「了解软件工作流程」空链接
- **问题描述**：`WelcomePage.tsx:30-32` 的「了解软件工作流程」按钮未绑定 `onClick`，首次用户点击无响应，容易产生「软件坏了」的错觉。
- **优化建议**：
  - 方案 A（推荐）：绑定到帮助页或新手引导弹窗；
  - 方案 B：若暂无文档，临时禁用并提示「即将上线」。
- **优先级**：高
- **涉及文件**：`yam-desktop/src/pages/WelcomePage.tsx`

#### 1.2 增加首次使用引导流程
- **问题描述**：首次打开仅有一个「添加专业」入口，没有解释「添加专业 → 采集数据 → 筛选院校」之间的关系。
- **优化建议**：增加步骤式新手引导，例如：
  1. 欢迎使用研喵；
  2. 添加需要采集的专业；
  3. 点击「数据采集」启动采集；
  4. 进入「工作区」筛选与比较院校。
- **优先级**：中
- **涉及文件**：`yam-desktop/src/pages/WelcomePage.tsx`

---

### 2. 数据加载与反馈

#### 2.1 支持后台刷新或可取消
- **问题描述**：点击「刷新数据」后，页面中央显示「加载中…」，但旧列表仍显示在下方；刷新耗时较长（3 秒以上仍可能未结束），期间用户无法取消，也无法进行其他操作。
- **优化建议**：
  - 将 `syncWorkspaceData` 循环同步改为可中断任务；
  - 在刷新按钮附近提供「取消刷新」按钮；
  - 或允许刷新在后台进行，页面仍可查看/筛选当前数据。
- **优先级**：高
- **涉及文件**：`yam-desktop/src/pages/WorkspacePage.tsx`

---

### 3. 筛选与搜索

#### 3.1 已选 Chip 支持点击重新编辑
- **问题描述**：当前筛选条件以 Chip 形式展示，用户只能点击「×」删除，不能直接点击 Chip 重新打开对应筛选面板调整已选项。
- **优化建议**：
  - 为每个已选 Chip 增加 `onClick` 事件；
  - 点击后打开对应筛选面板并自动定位到已选项；
  - 保持删除功能不变。
- **优先级**：中
- **涉及文件**：`yam-desktop/src/components/WorkspaceFilterPanel.tsx`

---

### 4. 数据展示（院校视图 / 招生计划视图）

#### 4.1 聚合展开状态持久化
- **问题描述**：在院校视图中展开某院校后，切换专业 Tab 或点击刷新，展开状态会被重置，用户需要重新展开查看详情。
- **优化建议**：
  - 将 `expandedSchoolId` 持久化到 `localStorage` 或 URL query；
  - 切换专业/刷新后恢复上次展开状态。
- **优先级**：中
- **涉及文件**：`yam-desktop/src/pages/WorkspacePage.tsx`

#### 4.2 趋势图增加 hover tooltip
- **问题描述**：`TrendChart` 中数据点文字仅 8px-10px，多个点密集时难以看清具体数值；当前无悬停提示。
- **优化建议**：
  - 鼠标悬停在数据点上时显示 tooltip，包含年份和具体数值；
  - 保持现有动画效果不变。
- **优先级**：中
- **涉及文件**：`yam-desktop/src/pages/WorkspacePage.tsx`（TrendChart 组件）

#### 4.3 招生计划视图行信息密度优化
- **问题描述**：招生计划视图每行包含院校、专业、院系、方向、考试科目、分数线等信息，列数过多时在小屏上换行严重。
- **优化建议**：
  - 提供「紧凑 / 舒适」视图切换；
  - 或允许用户自定义显示/隐藏列；
  - 默认隐藏部分低频列（如详细方向），hover 时再展开。
- **优先级**：低
- **涉及文件**：`yam-desktop/src/pages/WorkspacePage.tsx`

---

### 5. 收藏与最近查看

#### 5.1 简化取消收藏路径
- **问题描述**：当前取消收藏需要先到「收藏」页，找到对应红星再点击；在工作区多专业聚合行上点击收藏星的语义不清晰。
- **优化建议**：
  - 在院校展开后的每个专业卡片上单独显示收藏星；
  - 点击红星即可直接取消该专业收藏；
  - 取消后显示 toast 提示，并提供「撤销」按钮。
- **优先级**：中
- **涉及文件**：`yam-desktop/src/pages/WorkspacePage.tsx`

---

### 6. 错误处理与恢复

#### 6.1 错误提示同时用 toast + 局部重试按钮
- **问题描述**：当前错误仅通过页面顶部横幅展示，当用户滚动到列表下方时可能看不到错误信息。
- **优化建议**：
  - 保留顶部横幅作为兜底；
  - 增加全局 toast 通知；
  - 在出错组件附近显示「重试」按钮。
- **优先级**：高
- **涉及文件**：`yam-desktop/src/pages/WorkspacePage.tsx` 等页面

#### 6.2 同步失败支持单独重试
- **问题描述**：`handleSync` 中单个专业同步失败仅打印 `console.warn`，用户不知道哪个专业失败，也无法单独重试。
- **优化建议**：
  - 在失败的专业 Tab 上显示错误图标或小红点；
  - 点击该 Tab 时显示失败原因和「重新同步」按钮；
  - 批量刷新结束后汇总展示失败列表。
- **优先级**：高
- **涉及文件**：`yam-desktop/src/pages/WorkspacePage.tsx`

## 暂不处理模块

| 模块 | 原因 |
|------|------|
| 导航与全局交互 | 用户确认当前 hover 下拉与前两个点问题不大；返回工作区重置专业的问题在实际测试中未复现。 |
| 专业选择与管理 | 用户确认当前状态可接受，暂不调整。 |
| 导出功能 | 用户要求延后处理，待 ISSUE-028 后续测试时再评估。 |
